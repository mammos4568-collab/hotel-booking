# ผู้ช่วยแนะนำที่พัก (แชท)

ไฟล์: `server/src/modules/assistant/` (`routes.js`, `interpret.js`, `respond.js`, `lexicon.js`) ·
`server/src/lib/hotelSearch.js` · `server/src/lib/landmarks.js` · `server/src/lib/hotelFeatures.js` ·
`client/src/components/AssistantWidget.jsx` · ทดสอบ `server/test/assistant.js`

---

## ทำไมทำเองแบบกฎ + คำสำคัญ (ไม่ใช้ AI ภายนอก)

- **ฟรี** ไม่ต้องมี API key ไม่มีค่าใช้จ่ายต่อข้อความ
- **ตอบได้แค่เรื่องในเว็บเรา** โดยโครงสร้าง: คำตอบมีแค่ (1) ผลค้นจากฐานข้อมูลจริง หรือ (2) ข้อความที่เขียนไว้ล่วงหน้า
  จึงไม่มีทางคุยนอกเรื่องหรือแต่งข้อมูลขึ้นเอง
- **อธิบายได้ทุกบรรทัด** ตอนพรีเซนต์ — ทุกคำตอบไล่ย้อนได้ว่ามาจากกฎข้อไหน
- ข้อแลกเปลี่ยน: เข้าใจเฉพาะรูปประโยค/คำที่สอนไว้ ไม่ได้ "เข้าใจภาษา" จริงแบบ AI

---

## การทำงาน

```
AssistantWidget (หน้าเว็บ)
   │  POST /api/assistant/chat  { message, context, lang }
   ▼
routes.js     rate limit 30 ข้อความ/นาที · ยาวไม่เกิน 300 ตัวอักษร · คำหยาบ → ขอให้สุภาพ
   │          context มาจากหน้าเว็บ = ข้อมูลจากผู้ใช้ → sanitizeFilters() รับเฉพาะค่าที่รู้จัก
   ▼
interpret.js  ข้อความ → { intent, filters }   (ฟังก์ชันล้วน ไม่แตะฐานข้อมูล ทดสอบได้ตรงๆ)
   ▼
respond.js    intent → ค้นฐานข้อมูลจริง (searchHotels ตัวเดียวกับหน้าค้นหา) → ข้อความ + การ์ด + ปุ่มถามต่อ
   │
   ▼  { reply, hotels, chips, suggestions, filters, searchUrl }
หน้าเว็บแสดงผล แล้วส่ง filters กลับมาเป็น context ในข้อความถัดไป (คุยต่อเนื่องได้)
```

**server ไม่เก็บสถานะแชท** — ประวัติอยู่ในหน้าเว็บของผู้ใช้เท่านั้น ไม่บันทึกลงฐานข้อมูลหรือ log (PDPA)

## ตีความข้อความ (`interpret.js`)

1. **ทำข้อความให้เป็นรูปเดียวกัน** — ตัวเล็ก, เลขไทย → อารบิก, `2,500` → `2500`, `2k`/`สามพัน`/`พันห้า` → ตัวเลข,
   `สองคน` → `2 คน`, `คืนเดียว` → `1 คืน`, ตัวอักษรล่องหน
   (และแก้ปัญหา `normalize('NFKC')` ที่แยกสระ "ำ" เป็น "ํ"+"า" — ไม่แก้ "ชะอำ", "ต่ำกว่า" จะจับคำไม่ได้)
2. **อ่านทีละชนิดข้อมูล แล้วลบส่วนที่อ่านแล้วออก** ก่อนอ่านชนิดถัดไป

   | ลำดับ | อ่านอะไร | ตัวอย่าง |
   |---|---|---|
   | 1 | ชื่อโรงแรม | "Skyline Tower", "Patong Bay Beach Resort" |
   | 2 | สถานที่: เมือง / ย่าน / จุดเที่ยว / ที่ที่ยังไม่มีบนเว็บ | "เชียงใหม่", "แถวสุขุมวิท", "ใกล้ประตูท่าแพ", "เกาะสมุย" |
   | 3 | วันที่ | "12-14 พ.ย.", "สุดสัปดาห์นี้", "ศุกร์หน้า", "ปีใหม่", "12/11/2569" |
   | 4 | จำนวนคืน / ห้อง / คน / ดาว | "3 วัน 2 คืน", "2 ห้อง", "ผู้ใหญ่ 2 เด็ก 1", "ห้าดาว" |
   | 5 | งบประมาณ (ดูคำรอบตัวเลข) | "ไม่เกิน 3000", "ไม่ต่ำกว่า 2000", "ประมาณ 3000", "ทั้งทริป 10000", "$100" |
   | 6 | เรื่องที่ไม่มีข้อมูล | "หมอก", "พาหมาไปได้ไหม" |
   | 7 | วิว / บรรยากาศ | "วิวภูเขา", "ร่มรื่น", "เงียบสงบ", "ริมแม่น้ำ" |
   | 8 | สิ่งอำนวยความสะดวก / ประเภทที่พัก | "มีสระ", "ไม่เอาสระ", "รีสอร์ท", "วิลล่า" |
   | 9 | การเรียง | "ถูกกว่านี้", "รีวิวดีที่สุด", "หรูๆ" |

   **ทำไมต้องลบส่วนที่อ่านแล้วออก:** "เชียงใหม่" อ่านเป็นเมืองแล้ว คำว่า "ใหม่" ข้างในจะไม่ถูกอ่านซ้ำ ·
   "12-14 พ.ย." อ่านเป็นวันที่แล้ว เลข 12, 14 จะไม่ถูกนับเป็นงบประมาณ · ลบโดยแทนด้วยช่องว่างยาวเท่าเดิม
   ตำแหน่งตัวอักษรจึงไม่เลื่อน (ใช้ดูลำดับวันเช็กอิน/เช็กเอาต์ และดูคำปฏิเสธ "ไม่เอา…" ข้างหน้าได้)

   **คำยาวจับก่อนเสมอ:** รวมคำทั้งหมดเป็น regex เดียวเรียงจากยาวไปสั้น → "ครอบครัว" ไม่ถูกอ่านเป็น "ครัว",
   "สระส่วนตัว" ไม่ถูกอ่านเป็น "สระ" · ภาษาอังกฤษต้องเป็นคำเต็ม ("bar" ไม่อยู่ใน "barbecue")
3. **รวมกับเงื่อนไขเดิม** (คุยต่อเนื่อง): "โรงแรมภูเก็ต 2 คน" → "มีสระไหม" = ภูเก็ต + 2 คน + สระ ·
   "แล้วกระบี่ล่ะ" = เปลี่ยนแค่เมือง · "เริ่มใหม่" = ล้าง · พูดถึงโรงแรมหนึ่งอยู่แล้วถาม "มีสระไหม" = ถามว่า
   **โรงแรมนี้**มีไหม (ไม่ใช่เพิ่มตัวกรอง)
4. **ตรวจวันที่** (ไม่ย้อนหลัง, ไม่เกิน 30 คืน) และ **คนเยอะเกินห้องเดียว** → คำนวณจำนวนห้องให้ (6 คน → 2 ห้อง)
5. **เลือกเจตนา**: คำถามทั่วไป (ยกเลิก/จ่ายเงิน/PDPA …) · ที่ที่ยังไม่มี · รายชื่อเมือง · จุดเที่ยวในเมือง ·
   ข้อมูลโรงแรม · ค้นหา · ทักทาย · นอกขอบเขต → ปฏิเสธสุภาพพร้อมตัวอย่างคำถาม

## ตอบกลับ (`respond.js`)

- **ค้นหา** ใช้ `searchHotels()` ตัวเดียวกับหน้า `/search` → ผลตรงกัน และมีปุ่ม "ดูทั้งหมด" พาไปหน้าค้นหาด้วยเงื่อนไขเดิม
- **ไม่เจอเลย → ผ่อนเงื่อนไขทีละข้อ** (ข้อที่สำคัญน้อยก่อน) แล้วบอกตรงๆ ว่าผ่อนข้อไหน เช่น
  "ไม่มีที่ตรงทุกเงื่อนไข แต่ถ้าไม่จำเป็นต้องติดชายหาด มีตัวเลือกเหล่านี้" · "ขยับงบขึ้นได้ (ถูกสุดเริ่มต้น ฿2,530/คืน)"
- **วิว/บรรยากาศหลายข้อแต่ไม่มีที่ไหนตรงครบ** → แสดงที่ที่ตรงบางข้อ เรียงจากตรงมากสุด
- **ยกประโยคจากคำอธิบายจริง** เป็นหลักฐานบนการ์ด เช่น ✓ วิวภูเขา — "ห้องพักวิวภูเขา พร้อมระเบียงส่วนตัว"
  และ ✗ เมื่อคำอธิบายไม่ได้พูดถึง → ผู้ใช้เห็นว่าทำไมถึงแนะนำ ไม่ใช่เชื่อลอยๆ
- **ระยะทาง** ใช้สูตร Haversine (ระยะเส้นตรงบนผิวโลก รัศมี 6371 กม.) จากพิกัดโรงแรมในฐานข้อมูล —
  บอกผู้ใช้เสมอว่าเป็นระยะเส้นตรงโดยประมาณ ไม่ใช่ระยะเดินทาง

  ```
  d = 2R · asin( √( sin²(Δlat/2) + cos(lat1) · cos(lat2) · sin²(Δlng/2) ) )
  ```
- **เรื่องที่ไม่มีข้อมูล** (หมอก อากาศเย็น สัตว์เลี้ยง ที่ชาร์จรถไฟฟ้า …) → บอกตรงๆ ว่าข้อมูลที่พักไม่ได้ระบุ ยืนยันไม่ได้
- ราคาในข้อความเขียนเป็น `{{price:1234}}` → หน้าเว็บแปลงเป็นบาท/ดอลลาร์ตามที่ผู้ใช้เลือก
- ข้อความมี 2 ภาษาตามภาษาของหน้าเว็บ

## ตัวอย่าง (ใช้ทำสไลด์ได้)

| ผู้ใช้พิมพ์ | ผู้ช่วยเข้าใจว่า | ตอบ |
|---|---|---|
| ภูเก็ต 2 คน สุดสัปดาห์นี้ งบไม่เกิน 4000 | ภูเก็ต · เสาร์→อาทิตย์ · 2 ท่าน · ≤ ฿4,000/คืน | ที่พักที่ว่างจริงพร้อมราคารวม |
| มีโรงแรมวิวภูเขา มีหมอก บรรยากาศร่มลื่นไหม | วิวภูเขา + ร่มรื่น (หมอก = ไม่มีข้อมูล) | บอกว่ายืนยันเรื่องหมอกไม่ได้ + ที่ที่ตรงบางข้อพร้อมหลักฐาน |
| อยากพักใกล้ประตูท่าแพ | ใกล้ประตูท่าแพ (เชียงใหม่) | เรียงใกล้สุดก่อน: Old City Lanna House ~700 ม. … |
| Old City Lanna House ห่างจากดอยสุเทพเท่าไหร่ | ถามระยะทางของโรงแรมนี้ | ประมาณ 7.2 กม. (เส้นตรง) |
| 6 คน ที่กรุงเทพ | 6 ท่าน → อย่างน้อย 2 ห้อง | บอกว่าคิดเป็น 2 ห้องให้ + ที่พักที่รับได้ |
| ใกล้สนามบิน | ไม่รู้ว่าเมืองไหน | ถามกลับพร้อมปุ่ม สุวรรณภูมิ / ดอนเมือง / ภูเก็ต … |
| ที่พักที่ชะอำ | ยังไม่มีบนเว็บ ใกล้สุดคือหัวหิน | บอกตรงๆ + แนะนำที่พักหัวหิน |
| ยกเลิกการจองได้ไหม | คำถามทั่วไป | กติกาจริงของระบบ (ยกเลิกฟรีก่อนวันเช็กอิน) + ลิงก์ |
| ช่วยเขียนเรียงความให้หน่อย | นอกขอบเขต | ปฏิเสธสุภาพ + ตัวอย่างคำถามที่ถามได้ |

## เพิ่มความสามารถ

- คำใหม่ (เมือง ย่าน วิว ประเภทที่พัก เดือน …) → `server/src/modules/assistant/lexicon.js`
- จุดเที่ยวใหม่ (ชื่อ + พิกัด) → `server/src/lib/landmarks.js`
- วิว/บรรยากาศใหม่ (คำที่ต้องเจอในคำอธิบาย) → `server/src/lib/hotelFeatures.js`
- โรงแรม/เมืองที่แอดมินเพิ่ม ผู้ช่วยรู้จักชื่อภายใน 1 นาทีโดยไม่ต้องแก้โค้ด (โหลดรายชื่อจากฐานข้อมูล cache 1 นาที)
- เพิ่มประโยคทดสอบใน `server/test/assistant.js` ทุกครั้ง แล้วรัน `node server/test/assistant.js`
  (ส่วนตีความไม่ต้องเปิด server · ส่วน API ต้องเปิด server)
